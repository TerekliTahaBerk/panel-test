# ADR-0006 — Alan ve modül sınırları

- Durum: Kabul edildi — Faz 01 teknik tasarım; uygulama sonraki fazlarda.
- Tarih: 2026-10-30
- Sahip: teknik mimari sorumlusu; açık iş sahipleri Faz 01 raporunda.

## Bağlam

Faz 00 Next.js ve feature sunum yapısı kurulu; legacy lib/panel geniş sorumluluk taşıyor.

## Karar

Modüler monoliti koru; server alan servisleri, dar sözleşmeler ve tek DB transaction orkestrasyonu.

## Değerlendirilen alternatifler

Microservice; legacy dizinlerini aynen kopyalama; UI içinde doğrudan Prisma sorguları.

## Gerekçe

Aşamalı teslim ve daha az operasyon yükü.

## Sonuçlar

Çapraz modül iç repository import yasağı ve ortak AuditWriter portu gerekir.

## Güvenlik değerlendirmesi

Server-only sınırı ve ortak tenant/policy katmanı test edilir.

## Açık sorular

Outbox yalnız teslim garantisi gereken alan fazında eklenecek.
