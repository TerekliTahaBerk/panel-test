# ADR-0007 — Veritabanı ve migration stratejisi

- Durum: Kabul edildi — Faz 01 teknik tasarım; uygulama sonraki fazlarda.
- Tarih: 2026-10-30
- Sahip: teknik mimari sorumlusu; açık iş sahipleri Faz 01 raporunda.

## Bağlam

PostgreSQL ilişkisel bütünlüğe uygun; legacy db push SQL kısıtlarını kaybettirmiş.

## Karar

PostgreSQL + Prisma; migration SQL kaynak; runtime pooled/migrator direct bağlantısı; izole sentetik CI DB.

## Değerlendirilen alternatifler

NoSQL; db push ile bootstrap; legacy migration geçmişini taşıma.

## Gerekçe

FK, transaction ve incelenebilir SQL güvenlik kısıtları sağlar.

## Sonuçlar

RLS/CHECK/partial index/trigger catalog testleri gerekir; ORM şeması tek başına yeterli değildir.

## Güvenlik değerlendirmesi

Runtime DDL yetkisiz; üretim reset yok; secret ve müşteri verisi kopyalanmaz.

## Açık sorular

Provider, PostgreSQL/Prisma/driver sürümü ve RPO/RTO onayı Faz 02 öncesi.
