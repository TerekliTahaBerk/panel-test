# ADR-0009 — Faz 02 çalışma zamanı ve kapalı provisioning politikası

- Durum: Kabul edildi; Faz 01 alan modeli korunur.
- Tarih: 2026-10-30

PostgreSQL 17.10, Prisma CLI/Client/adapter-pg 7.10.1 ve pg 8.23.1 seçildi.
Node 22.12+ (CI: 22; yerel doğrulama: 24.21.0), TypeScript 5.9.3 kullanılır.
Prisma 8 kayıt tarihinde sürüm adayıdır; `latest` izlenmez. Prisma 7'nin Rust gerektirmeyen
istemcisi ve pg adapter'ı tek runtime client ile çalışır. CLI URL'si `prisma.config.ts`
içindeki DIRECT_URL; runtime URL'si adapter üzerinden DATABASE_URL'dir.

Resmî kaynaklar: [Prisma 7 PostgreSQL](https://www.prisma.io/docs/orm/v7/core-concepts/supported-databases/postgresql),
[sistem gereksinimleri](https://www.prisma.io/docs/orm/v7/reference/system-requirements),
[SECURITY DEFINER](https://www.postgresql.org/docs/17/sql-createfunction.html),
[RLS](https://www.postgresql.org/docs/17/ddl-rowsecurity.html).

Sağlayıcı/hosting seçilmez. Compose izole PostgreSQL sunar; yerel doğrulamada Docker daemon
kapalı olduğu için aynı PostgreSQL 17.10'un ayrı `/private/tmp` kümesi kullanıldı.
Normal geliştirici akışı Docker'dır; native test kümesi uygulama bağımlılığı değildir.

Ürün kurulum kotası Faz 05 kararıdır. DB'nin `security.provisioning_quota()` politikası
varsayılan 0 döndürür. Test bootstrap'ı yalnız loopback üzerinde `panel_*_test` adlı yeni
DB'de bu politikayı 5 olarak değiştirir. Production'da principal adapter ve provisioning
servisi koşulsuz kapalıdır; ortam değişkeniyle açma seçeneği yoktur. Faz 03/05; gerçek MFA,
CSRF/origin, rate limit ve ürün kotası tamamlanmadan bu kapıları açamaz.

Sahiplik kısıt trigger'ı migrator'ın SECURITY DEFINER fonksiyonudur: yalnız
Organization/Membership satırlarını okuyup kurum satırını kilitler ve geçersiz durumu reddeder.
Migrator'a özel RLS politikası FORCE altında bu kontrolü mümkün kılar. PUBLIC EXECUTE
kaldırılmıştır. Provisioning fonksiyonu bundan ayrıdır: sahibi tablo sahibi olmayan,
NOLOGIN/NOBYPASSRLS `panel_provision_owner` rolüdür. Migrator bu role yalnız migration
sırasında SET ROLE yapabilir; kalıtım kapalıdır. Runtime/caller hiçbir ayrıcalıklı role üye değildir.
